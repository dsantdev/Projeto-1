# Projeto-1
O Projeto 1 é o primeiro projeto desenvolvido na aula de Desenvolvimento Front End do Curso de Formação Acelerada do Instituto Hardware.

Aplicação web para cadastrar, acompanhar, filtrar e excluir tarefas do dia a dia, com os dados salvos no próprio navegador.

Autora: Daniele Sant'Anna Vaz

##Descrição e objetivo

Manter uma rotina organizada fica mais fácil quando as atividades estão registradas, com prioridade e prazo definidos.

O objetivo do exercício é praticar, utilizando apenas HTML, CSS e JavaScript:

formulários e validação;
manipulação do DOM;
eventos;
funções, arrays, condicionais e repetições;
armazenamento de dados com localStorage;
alteração de classes CSS por meio de JavaScript.
Tecnologias utilizadas
HTML5: estrutura da página e formulário.
CSS3: layout e identidade visual.
JavaScript (puro): lógica da aplicação, sem bibliotecas ou frameworks.
localStorage: armazenamento das tarefas no navegador.
Git: versionamento do projeto.
Principais funcionalidades
Cadastro de tarefas com descrição, categoria, prioridade (alta, média ou baixa) e data de conclusão.
Validação do formulário: mensagens de aviso quando algum campo não foi preenchido.
Listagem dinâmica: as tarefas aparecem na tela sem recarregar a página.
Concluir e desfazer: tarefas concluídas ficam com o texto riscado, outra cor e a indicação "Concluída".
Exclusão com confirmação: o sistema pergunta antes de remover a tarefa.
Filtros por situação (todas, pendentes, concluídas) e por categoria. Os filtros afetam apenas a visualização, nunca os dados salvos.
Indicadores de total, pendentes e concluídas, atualizados automaticamente.
Persistência: as tarefas continuam disponíveis depois de atualizar a página ou fechar o navegador.
Mensagem de estado inicial quando ainda não há tarefas cadastradas.
